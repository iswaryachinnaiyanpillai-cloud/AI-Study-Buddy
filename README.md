# 🤖 AI Study Buddy

## 📌 Project Overview

AI Study Buddy is an AI-powered student learning companion designed to make studying smarter, organized, and more engaging.

It provides personalized learning tools, study planning, progress tracking, quizzes, and motivational support to help students achieve their academic goals.

---

## ✨ Features

### 🏠 Welcome Page
- Interactive landing page with AI Study Buddy introduction.
- Easy navigation using the Explore Now button.

### 📅 Smart Study Planner
- Add subjects and study hours.
- Create a personalized study plan.

### 🧠 Quiz Zone
- Test knowledge through interactive questions.
- Get instant answer feedback.

### 📝 Notes Hub
- Write and organize important study notes.

### 📊 Progress Pulse
- Track completed study tasks.
- Visual progress monitoring.

### ✨ Daily Spark
- Get motivational messages for consistent learning.

### 🌙 Dark Mode
- Switch between light and dark themes for better user experience.

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎯 Objective

The goal of AI Study Buddy is to provide students with a simple and effective platform to manage their learning journey using smart digital tools.
